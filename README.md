# موقع الذكاء المكاني للحلول الرقمية

نسخة الإطلاق العربية: 19 صفحة ثابتة في `dist/ar/`: الرئيسية، خدماتنا، القطاعات، من نحن، تواصل معنا، الخصوصية، والمسارات الخمسة، والعروض الثلاثة، وخمس صفحات مجالات لمسار البيانات الجيومكانية (مثل `ar/services/geospatial-data/quality-updates.html`). الخدمات تُعرض للقراءة فقط دون صفحات خاصة بها.

## البناء
```
python build.py
```
المتطلبات: Python 3.9+ ومكتبة Jinja2 (`pip install jinja2`). السكربت يقرأ `src/` ويكتب الصفحات في `dist/`. للمعاينة افتح `dist/index.html`.

## المجلدات
- `src/content/`: كل النصوص بصيغة JSON. `site.json` للاسم والقائمة وترتيب المسارات والعروض وربط كل صفحة بصورتها (`pictures`) وتسميات بطاقات المسارات (`track_labels`). `tracks/` للمسارات الخمسة وخدماتها ومجموعاتها، `offers/` للعروض الثلاثة، وملفات القطاعات والقيم و«من أين أبدأ» وسياسة الخصوصية. لإضافة صفحة داخلية لخدمة: ضع `"page": "<اسم>"` في خدمتها داخل ملف المسار، وأنشئ `services/<المسار>/<اسم>.json` (القالب `service.html` جاهز). نصوص صفحات الخدمات الـ16 القديمة لمسار البيانات الجيومكانية محفوظة في `_archive/geospatial-data-services/`.
- `src/templates/`: `base.html` (الترويسة بقوائمها المنسدلة والتذييل)، `_macros.html` (القطع المتكررة: رأس الصفحات، بطاقات الصور، الفسيفساء، الشريط الختامي)، وقوالب المسار والخدمة والعرض.
- `src/pages/`: الرئيسية، خدماتنا، القطاعات، من نحن، تواصل معنا، سياسة الخصوصية.
- `src/assets/`: `css/style.css` و`js/main.js` (القوائم، لوحة صور الهيرو، التبويبات، نموذج التواصل) و`img/`.
- `dist/`: الناتج. لا يُعدَّل يدويًا، يُعاد بناؤه.
- `_archive/`: نسخ سابقة للرجوع إليها فقط: نسخة الصفحة الواحدة (`single-page/`)، والرسومات القديمة (`old-art/`)، وأول نسخة من سكربت البناء و`doc.xml`.
- `نصوص موقع الذكاء المكاني.md`: نسخة من مستند النصوص (13 نوفمبر 2026).
- `gen_img.py`: يولّد صورتي `landcover.jpg` و`blueprint.jpg` في `src/assets/img/`.

## التصميم
على نمط صفحات المنصات المؤسسية (مستوحى من فكرة موقع Esri، بهوية الشركة): قوائم منسدلة كبيرة، هيرو داكن بصورة على عرض الشاشة ولوحة صور تتبدل كل 5 ثوانٍ مع زر إيقاف، بطاقات صور عليها النص، تبويبات عروض البداية، فسيفساء المسارات، قسم داكن للقطاعات، وتذييل بأعمدة. الصفحات الداخلية لها رأس داكن بصورة المسار.
الألوان قريبة من Esri: أزرق `#0079c1` (غامق `#005e95`، وفاتح `#56c5ff` على الخلفيات الداكنة)، رمادي فحمي `#151515` للأقسام الداكنة، وخلفية بيضاء. الخط: Tajawal.
الصور: city وdunes وnetwork وdetect من النسخة السابقة، وlandcover وblueprint مولدتان. الشعار (`logo.svg`) هو شعار الدائرة والكثبان بألوانه الأصلية، ولم يُستبدل بعد بشعار الشبكة السداسية.

## الناقص قبل النشر
- نموذج التواصل يرسل الطلب إلى Netlify Forms (يعمل بعد النشر على Netlify فقط). بعد أول نشر: افتح لوحة Netlify ← Forms ← Form notifications ← Add notification ← Email، وأدخل info@simotechs.com ليصلك كل طلب على البريد، وفعّل حماية السبام. عند فتح الصفحة محليًا أو تعذّر الإرسال يعود النموذج لفتح برنامج البريد (mailto).
- التحقق من ترخيص خدمات الاستشعار عن بعد (صفحة المسار عليها شريط «معاينة داخلية»).
- المراجعة القانونية لسياسة الخصوصية واستكمال خاناتها.
- عبارات الحياد تجاه الموردين: تُحذف إن وُجدت علاقة تجارية مع مورد.
- النسخة الإنجليزية في `dist/en/` (بعد اعتماد العربية).
- في `dist/assets/img/` ست رسومات svg قديمة لم تعد مستخدمة، بقيت لأن حذف الملفات غير مفعّل. يمكن حذفها يدويًا.
